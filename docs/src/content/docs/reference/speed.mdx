Times exclude the first image. The first image at a new size takes a few seconds longer while Pneumam prepares for that size.

## Get the best speed

- Turn on FP8. It makes each image about twice as fast. In ComfyUI it is the `fp8` switch on Load Pneumam Model, and on the command line it is `--fp8`.
- Keep image sizes the same between runs, so you only wait for the first image once.
- Stay near 1024×1024 in total area, such as 832×1216 or 1216×832. Anima also draws best at these sizes.
- Use an RTX 50 series card, which is where Pneumam is fastest.
